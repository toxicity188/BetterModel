## ✨ Feats
### Player model resource pack optimization
Optimized player armor resource generation to reduce resource pack size (~390 KB reduction).

### Armor model toggle configuration
```yaml
# Core feature modules.
# Disable modules you don't need to save resources.
module:
  # Enables general entity models.
  model: true
  # Enables player-specific animations and models (e.g., custom limbs).
  player-animation: true
  # Enables player armor in player model.
  player-armor: true
```
Added a config option to toggle the player armor feature for servers not using vanilla Minecraft armor, slightly reducing server CPU usage and resource pack size.
