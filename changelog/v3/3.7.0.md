## ✨ Features

### Runtime Molang

- Animation keyframes can evaluate Molang expressions during playback using entity state, animation timing, and custom variables and functions. (#481)
- The `kr.toxicity.model.api.animation.keyframe` package stores constant values separately from runtime expressions. Models with constant keyframes keep their numeric playback path and avoid runtime Molang evaluation.

### Smaller resource packs

- Improved cube grouping by finding more rotations that cubes can share while preserving their orientation. This reduces the number of item model files generated for rotated cubes.

### Expanded MythicMobs integration

- Added the `scale` and `nofall` mechanics and the `<caster.model.yaw>` placeholder.
- Added conditions for model presence, part visibility, hitboxes, and mount state. Added targeters for mounted models, passengers, and drivers.

### Model Importer API

- Added `ModelImporter` so add-ons can register support for custom model file extensions. The separate [bettermodel-ysm](https://github.com/toxicity188/bettermodel-ysm) add-on uses this API to import `.ysm` models.

### Blockbench animation blend weight

- Added support for Blockbench's `blend_weight` property. A numeric value or runtime Molang expression controls the strength of an animation's transforms. The default weight is `1`.

### Emissive textures

- Added automatic emissive rendering for textures with the `emissive` or `additive` render mode, or a filename ending in `_e` before the file extension. (#404)

## ⚡ Optimizations

- Skip animation packet bundling when a model has no viewers while keeping its animation state ticking.
- Reuse animation packet appenders and reduce overhead in `PriorityMap` and collection utilities.
- Balance parallel loading across workers using estimated task sizes.

## 🔧 Fixes

- Fixed `meg-client-mod` integration on Fabric.
- Fixed animation packet bundling and rendered bone world position calculations.
- Preserve hitbox packet conversion until the client removes the hitbox. (#468)
- Fixed a vector dot product compatibility issue on some older Minecraft versions. (#480)
